# Recon board

A small web page for the used-car reconditioning team. Every car waiting to be made front-line ready shows as a card in its current stage; the card colour shows how long it has sat in that stage.

Run: `python server.py`, then open http://localhost:8080. Sign-in goes through the group's single sign-on; the text messages go through the paging service (stubbed out for now).
